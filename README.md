# Suluu Business — Управление бьюти-бизнесом

Suluu Business — это современная CRM-платформа и автономная экосистема для автоматизации операционных процессов в салонах красоты, бьюти-коворкингах и у частных мастеров. Приложение поддерживает учет записей (интерактивный календарь), смены мастеров, расчет сдельной зарплаты, клиентскую базу, каталог услуг и финансовый контур.

---

## Архитектура системы

```
┌─────────────────────────────────┐                 Realtime / REST                 ┌─────────────────────────────────┐
│         Фронтенд (SPA)          │ ──────────────────────────────────────────────> │             Backend             │
│          GitHub Pages           │ <────────────────────────────────────────────── │       Supabase (Postgres)       │
│    HTML5 / Tailwind / morphdom  │                 Websockets / JWT                │        Row Level Security       │
└─────────────────────────────────┘                                                 └─────────────────────────────────┘
```

- **Frontend**: Легковесный Single Page Application (SPA). Построен на базе чистого HTML5, CSS3 и ванильного JavaScript. Для быстрого обновления интерфейса без перезагрузки страниц используется библиотека `morphdom`. Стилизация выполнена с помощью Tailwind CSS (локальный билд).
- **Backend & Database**: Платформа **Supabase** (Бэкенд-как-сервис на базе PostgreSQL 15).
  - **Auth**: Регистрация, авторизация и сессионные JWT-токены.
  - **Database**: PostgreSQL с поддержкой сложных реляционных связей, триггеров и внешних ключей.
  - **Realtime**: Автоматическая фоновая синхронизация данных между всеми клиентами через WebSockets.
  - **Security**: Row Level Security (RLS) политики разграничивают доступ к записям СУБД между организациями (салонами) и ролями сотрудников.
- **PWA (Offline-First)**: Поддерживает установку на смартфоны и десктопы. Кэширование статических ресурсов с помощью Service Worker обеспечивает запуск приложения при отсутствии интернет-соединения.

## Функциональные возможности

| Модуль | Описание |
|:---|:---|
| **🚀 Лендинг** | Встречает новых пользователей. Содержит описание ролей, интерактивный демо-симулятор CRM-системы, справочники и форму обратной связи с редиректом в WhatsApp владельца. |
| **📊 Дашборд** | Аналитика выручки, визитов, среднего чека за выбранный период времени. Рейтинги мастеров и востребованности услуг. |
| **📅 Календарь** | Интерактивный таймлайн записей по часам в разрезе мастеров. Фильтрация, управление статусами визитов и поддержка мульти-услуг. |
| **👥 Сотрудники** | Карточки мастеров, привязка услуг, настройка личного расписания и процента заработной платы за смену. |
| **👤 Клиенты** | База контактов, детальная история посещений, автоматический подсчет оборота по каждому клиенту. |
| **💇 Услуги** | Каталог по категориям. Пакетный импорт шаблонов популярных бьюти-услуг (50+ готовых схем). |
| **💰 Финансы** | Учет касс и безналичных счетов салона (кошельки), доходы и расходы по категориям. Контроль кассовых смен сотрудников. |
| **⚙️ Настройки** | Профиль пользователя, реквизиты салона, выбор цветовой темы оформления и тумблер включения/выключения финансового учета (`use_finance`). |

*Примечание: Финансовый блок может быть полностью отключен владельцем салона, при этом все разделы транзакций, касс и смен будут скрыты из интерфейса.*

## Быстрый старт и Настройка

### 1. Подготовка бэкенда (Supabase)
1. Создайте новый проект на платформе [Supabase](https://supabase.com/).
2. Перейдите в раздел **SQL Editor** и создайте новый запрос.
3. Скопируйте содержимое файла [supabase_schema.sql](supabase_schema.sql) и выполните его. Это создаст все таблицы, индексы, вспомогательные функции, триггеры авторизации и настроит RLS-политики.
4. В разделе **API Settings** вашего проекта в Supabase скопируйте `Project URL` и `anon public API Key`.

### 2. Конфигурация подключения клиента
1. Откройте файл [js/api.js](js/api.js).
2. Замените значения констант `SUPABASE_URL` и `SUPABASE_KEY` (строки 5-6) на ваши скопированные ключи:
   ```javascript
   const SUPABASE_URL = 'ВАШ_SUPABASE_PROJECT_URL';
   const SUPABASE_KEY = 'ВАШ_SUPABASE_ANON_PUBLIC_KEY';
   ```

### 3. Локальный запуск приложения
1. Склонируйте репозиторий на локальную машину.
2. Запустите локальный HTTP-сервер в корневой папке репозитория (например, используя VS Code Live Server или выполнив `npx http-server ./`).
3. Откройте приложение в браузере. Вы попадете на стартовую страницу (лендинг).
4. Нажмите кнопку **Регистрация**, выберите роль **Владелец салона**, укажите название компании и завершите процесс. Начнется автоматическая инициализация данных.
