# Архитектура Suluu Business и структура модулей

---

## 1. Концепция Single Page Application (SPA)
Приложение Suluu Business построено по архитектуре SPA с рендерингом на стороне клиента и динамическим обновлением DOM-дерева через технологию **morphdom**. Это позволяет избежать накладных расходов традиционных фреймворков (React, Vue) при сохранении реактивности и высокой скорости работы.

### Схема взаимодействия компонентов SPA:
```
                   ┌──────────────────────────────────────┐
                   │               index.html             │
                   └──────────────────┬───────────────────┘
                                      │
                   ┌──────────────────▼───────────────────┐
                   │             js/state.js              │
                   │    (Единый источник истины / State)  │
                   └──────────────────┬───────────────────┘
                                      │  setState() / setUI()
                                      │  вызывает render()
                   ┌──────────────────▼───────────────────┐
                   │         js/core/engine.js            │
                   │        (Движок рендеринга)           │
                   └──────────────────┬───────────────────┘
                                      │
                   ┌──────────────────▼───────────────────┐
                   │         js/core/router.js            │
                   │     (Роутинг и верстка макета)       │
                   └──────────┬────────────────┬──────────┘
                              │                │
          [Unauthenticated]   │                │   [Authenticated]
     ┌────────────────────────┘                └────────────────────────┐
     │                                                                  │
┌────▼────────────────┐  ┌────────────────────┐            ┌────────────▼───────┐
│ js/pages/landing.js │  │  js/pages/auth.js  │            │ js/pages/layout.js │
│ (Рендеринг лендинга)│  │ (Экран авторизации)│            │  (Боковая панель + │
└─────────────────────┘  └────────────────────┘            │   контент страниц) │
                                                           └────────────┬───────┘
                                                                        │
                                                ┌───────────────────────┼───────────────────────┐
                                                │                       │                       │
                                      ┌─────────▼──────────┐  ┌─────────▼──────────┐  ┌─────────▼──────────┐
                                      │ js/pages/bookings.j│  │ js/pages/masters.j │  │ js/pages/finance.j │
                                      │ (Календарь записей)│  │ (Список персонала) │  │  (Финансовый блок) │
                                      └────────────────────┘  └────────────────────┘  └────────────────────┘
```

## 2. Потоки данных и Управление состоянием (Data Flow)
1. **Глобальный объект состояния (`window.state`)**: Описан в [state.js](file:///d:/%D0%A0%D0%B0%D0%B1%D0%BE%D1%87%D0%B8%D0%B9%20%D1%81%D1%82%D0%BE%D0%BB/Code%20Projects/BeautyPlace/business/js/state.js). Хранит в себе статус авторизации, данные о текущем салоне, списки мастеров, категорий, услуг, записей, транзакций, а также параметры фильтров и состояние модальных окон.
2. **Модификация состояния**: Выполняется исключительно через функции `window.setState(updates)` и `window.setUI(updates)`.
3. **Реактивный рендеринг**: Любой вызов `setState` или `setUI` автоматически запускает функцию `window.render()` в [engine.js](file:///d:/%D0%A0%D0%B0%D0%B1%D0%BE%D1%87%D0%B8%D0%B9%20%D1%81%D1%82%D0%BE%D0%BB/Code%20Projects/BeautyPlace/business/js/core/engine.js), которая:
   - Получает новую строку разметки из `window.renderApp()`.
   - Создает виртуальный DOM-элемент из строки с помощью `DOMParser`.
   - Сравнивает текущий реальный DOM `#app` с новым виртуальным деревом через алгоритм `morphdom`, заменяя только изменившиеся атрибуты, узлы и текстовые блоки.
   - Инициализирует иконки Feather (`feather.replace()`) и применяет активную тему оформления.

## 3. Каталог файлов проекта (Component Mapping)

- `index.html`: Единственная точка входа, загружающая CSS-стили, Tailwind, библиотеки `morphdom`, `feather-icons`, Supabase Client SDK, а также все JS-модули приложения.
- `css/style.css`: Глобальные стили приложения. Определяет палитру тем, стили стекломорфизма (`.glass-island`, `.glass-interactive-card`), анимации и переопределения стандартных UI-компонентов.
- `js/state.js`: Модель состояния приложения, функции обновления состояния и фильтров.
- `js/utils.js`: Вспомогательные утилитарные методы (форматирование дат, конвертация длительности времени в минуты/часы, расчеты сумм, вывод Toast-уведомлений).
- `js/api.js`: Сервисный слой для прямого взаимодействия с базой данных Supabase. Содержит маппинг данных (конвертация `snake_case` БД в `camelCase` JS) и методы для работы со всеми сущностями.
- `js/core/engine.js`: Движок обновлений интерфейса на базе `morphdom`.
- `js/core/router.js`: Маршрутизатор приложения. Контролирует отрисовку разметки в зависимости от авторизации и текущей вкладки, а также реализует проверку прав доступа (`window.hasPermission`).
- `js/pages/`:
  - `landing.js`: Промо-страница (лендинг) с интерактивным симулятором, описанием ролей и подробным руководством пользователя.
  - `auth.js`: Страница входа и регистрации пользователей с возможностью привязки к салону и выбора ролей.
  - `dashboard.js`: Панель аналитики. Выводит общую выручку, число визитов, графики выручки и популярные услуги. Поддерживает фильтрацию за сегодня, за все время или за выбранный период.
  - `bookings.js`: Интерактивный календарь (таймлайн по часам) и табличный вид записей. Содержит логику создания, редактирования и смены статусов визитов.
  - `masters.js`: Страница управления персоналом. Вывод списка мастеров, управление их расписанием, услугами и процентными ставками.
  - `clients.js`: База клиентов с поиском, статистикой посещений и общей выручкой по каждому клиенту.
  - `services.js`: Управление каталогом услуг. Поддерживает работу с категориями и глобальными шаблонами.
  - `finance.js`: Модуль транзакций, кошельков и кассовых смен (сменных отчетов).
  - `settings.js`: Настройки профиля пользователя и салона (включая переключатель учета финансов `use_finance`).
  - `job_search.js`: Раздел поиска работы для мастеров и менеджеров, ожидающих подтверждения от владельцев салонов.
  - `super_admin_panel.js`: Глобальная панель управления справочниками и аудита системы для роли `super_admin`.
